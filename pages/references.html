How this was compiled

Vendor numbers are reproduced as published and labeled with the vendor's name where they are specific to that vendor's equipment (for example thread pilot ranges and machining envelopes). General rules of thumb come from common machining and additive manufacturing practice and are given as conservative design values. Where sources disagree, the page gives the range and a conservative choice.

Report a correction

If a value here disagrees with your vendor's current documentation, the vendor is right. Open an issue or pull request on the project repository so the page can be updated.
