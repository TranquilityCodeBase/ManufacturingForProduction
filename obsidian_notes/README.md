# Obsidian DFM Notes

Markdown notes for an Obsidian vault with the same CNC and 3D printing design-for-manufacturing data as the website.

## Install
1. Copy the `CNC_3DP_Design_For_Manufacturing` folder into your vault (for example `Vaults/CNC_3DP_Design_For_Manufacturing`).
2. Open `00_CNC_3DP_DFM_Table_Of_Contents.md` as the entry point.
3. If your vault uses a different TOC convention (note name, heading style, MOC tags), rename or restyle the TOC note to match. Links use note names, so moving notes between folders will not break them.

## Layout
- `01_CNC_Machining` - tolerances, corners and pockets, walls, milling, turning, setups, stock sizes, materials, finishes, cost tips
- `02_Holes_And_Threads` - thread and hole rules, ProtoLabs pilot hole tables, tap and clearance drill charts
- `03_3D_Printing` - process selection, materials, internal passages, overhangs, quality and cost tips
- `04_References` - source links

The thread and tap drill tables come from the same data files the website uses (`js/data/`), so the two stay in sync.
